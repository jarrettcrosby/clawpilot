# Knowledge Inbox

Use this folder only for short-lived capture. Before a pull request is promoted, move each durable conclusion into its owning module or operations contract, add a decision when the tradeoff is durable, update release copy, and delete the processed capture note.

Start from the [ClawPilot Context Map](../maps/context-map.md). The repository does not retain chronological daily worklogs after their useful information has been refactored.
