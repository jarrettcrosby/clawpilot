# ClawPilot Identity

ClawPilot uses a CP route mark: the C is a guided path, the P is the pilot structure, and the green signal point indicates a ready execution handoff. The geometry follows the disciplined monoline character used across the broader brand family without copying an Eigen Racing team mark or importing that application's assumptions.

## Assets

- `app_src/public/brand/clawpilot-mark.svg`: primary interface mark
- `app_src/public/brand/clawpilot-mark-mono.svg`: monochrome fallback
- `app_src/public/brand/clawpilot-lockup.svg`: horizontal product lockup
- `app_src/public/brand/email/clawpilot-mark-email.png`: raster email and Apple-touch asset

## Color Roles

- on-surface: `#E4E1EC`
- guided route: `#7EABFF`
- ready signal: `#4FD1B8`
- application background: `#0F0F13`

Use the mark at stable square dimensions. Do not replace it with a generic rocket, bot, claw, or racing symbol.
