# Legacy Vault Reconciliation

## Scope And Result

On September 21, 2026, the separate local vault `Jarrett Crosby - ClawPilot` was reconciled against the canonical ClawPilot repository. Its 111 Markdown files are individually accounted for below: 77 superseded, 31 retained as historical evidence, 2 already covered, and 1 useful process incorporated into the current [Vault Map](../README.md). No raw agent logs, personal agent mirrors, or credential material were copied into this repository or its application search index.

The old folder remains a preserved reference, not a current source of requirements. Its Home and README carry retirement notices. The desktop Obsidian registry was initially pointed at the canonical repository root; it now points to that same repository's `docs/` directory so dependencies and generated files are not indexed. The separate Eigen Racing vault registration was left unchanged. A full pre-change backup and SHA-256 note manifest are retained locally under `Documents/ClawPilot-Recovery/2026-09-21/obsidian-reconcile.HuT6C2`. All 3,913 backed-up files matched before edits.

After the docs-only switch, Obsidian stalled while loading its old repository cache. A second backup under `Documents/ClawPilot-Recovery/2026-09-21/obsidian-docs-vault-before-switch/` preserved the notes, settings, and registry. Registering the same `docs/` folder with a fresh local cache identity restored startup; the old cache and all notes were retained. Desktop verification opened Home and the graph successfully. The graph now excludes templates and unresolved external-file nodes and colors current notes by area, with historical notes distinguished. This is a documentation graph, not a runtime dependency graph; the latter is maintained in [LikeC4](../architecture/clawpilot-likec4.md).

## Current Navigation And Search

- [Vault Map](../README.md) is the human entry point. The eight previously unreachable vault-only notes are now linked and identified as current references or historical compatibility/cutover evidence.
- `npm run verify:docs` now rejects any non-template Markdown note under `docs/` that is unreachable from the Vault Map, in addition to its existing metadata and link checks. Templates are authoring scaffolds, not orphan knowledge.
- The app catalog remains 34 explicitly application-visible repository notes, including one historical incident. Vault-only operating evidence is deliberately not published to application search.
- A read-only production audit at deployed commit `40c12a44b967a09bdea7592da78470fe326b8ea9` found 186 documents with current 256-dimension vectors, matching content hashes, and 186 completed embedding jobs; no pending, failed, missing, or stale embeddings. The repository catalog matched that deployed source in all four indexed workspaces.
- Those production observations are dated evidence, not a guarantee about later edits. Unreleased local documentation is not claimed to be deployed or re-embedded. The local hashed vector model is not an external neural embedding service; see [Knowledge Vault Organization](knowledge-vault-organization.md) and [Local-first knowledge retrieval](../decisions/0004-local-first-knowledge-retrieval.md).
- Old Smart Connections cache files are preserved only with the retired vault. They are not imported or treated as the canonical application vector index.
- Old-vault scripts still exist in their historical OpenClaw workspace, but the inspected cron registry had zero enabled jobs. No gateway, unrelated automation, or runtime was changed.

## Disposition Rules

**Superseded** means use the linked current contract instead of the old guidance. **Historical evidence** means the original stays in the preserved vault for provenance; the target is the current owner of the topic, not a claim that raw logs were copied there. **Covered** means useful principles already exist in the target. **Incorporated** means the bounded manual review checklist was added, without reviving obsolete cron, ports, or deployments.

These mappings do not authorize resuming abandoned organization migrations, reactivating retired infrastructure, or executing instructions from old logs. Refer to the active [environment contract](clawpilot-environments.md) and [on-demand development runbook](development-on-demand.md).
