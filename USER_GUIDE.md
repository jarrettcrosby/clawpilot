# User Guide Pointer

Current user behavior is documented in the active contracts linked from the [ClawPilot Knowledge Index](docs/index.md). The former chronological guide accumulated contradictory intermediate UI states and was consolidated. This path remains only because the Next.js output-tracing configuration still names it; Git history preserves the original guide.

Each active ClawPilot user membership receives a personalized **ClawPilot User Guide** as the first document in the in-app Docs module. ClawPilot refreshes that guide from current behavior so users do not depend on this compatibility pointer.
